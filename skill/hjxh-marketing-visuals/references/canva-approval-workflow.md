# 皇家小虎 Canva 审批改图流程

## 默认适用范围

用于皇家小虎通用营销图的可编辑画布制作和按批准改图。适用于用户只发图、发图加修改要求、要求做成 Canva 画布、要求导出图片、要求按审批修改的场景。

## 默认交付

- Canva 可编辑画布
- 导出图片
- 审核/修改说明

## 输入模式

1. 用户只发图：先审核，不直接改图。输出“可直接改 / 需批准 / 不建议改”的修改清单。
2. 用户发图并提供修改要求：先按要求做风险分级；低风险项可直接纳入执行，高风险项必须等待用户明确批准。

## 严格审批规则

可直接改：
- 间距、对齐、留白、层级
- 不改变事实和品牌识别的轻微背景氛围
- 不改变文案含义的排版优化

必须先批准：
- Logo、品牌色、字体
- IP 身份、表情、比例、新动作、新视角
- 真实产品素材、产品结构、产品数量、口味和卖点
- 主标题、价格、促销信息、活动条款
- 会影响品牌识别、商业事实或消费者理解的修改

不建议改：
- 用 ImageGen 重画或仿制 Logo
- 用生成式图片替代真实产品素材
- 让 IP 偏离标准身份或产生未标注的新动作
- 虚构产品、夸大份量、修改价格或促销规则

## 工具分工

- Canva：负责最终可编辑画布、真实 Logo、真实产品素材、标准 IP、中文文字、精确排版和导出图片。
- ImageGen：只负责背景、场景、氛围、非品牌核心视觉。生成结果不得包含仿制 Logo，不得替代真实产品图。
- Codex：负责审核、风险分级、审批清单、工具选择、修改说明和交付前复核。

## 执行顺序

1. 读取品牌规范、制作流程、审核流程、审核模板和素材 manifest。
2. 判断输入模式。
3. 审核原图或修改要求，列出三类修改项。
4. 等待用户批准所有高风险项。
5. 批准后制作 Canva 可编辑画布；必要时先用 ImageGen 生成不含 Logo 的背景或场景。
6. 在 Canva 中放置真实 Logo、真实产品素材、标准 IP 和文本。
7. 导出图片。
8. 按审核模板执行交付前复核。
9. 交付 Canva 画布、导出图和审核/修改说明。

## 输出格式

审批前输出：

```markdown
## 审核结论
结论：等待批准 / 可直接执行 / 不建议执行

## 可直接改
- ...

## 需你批准
- ...

## 不建议改
- ...

## 推荐执行方案
- Canva 处理：...
- ImageGen 处理：...
```

交付时输出：

```markdown
## 交付内容
- Canva 可编辑画布：...
- 导出图片：...
- 审核/修改说明：...

## 已执行修改
- ...

## 审核结论
结论：通过 / 不通过 / 需确认
```
