# 已确认的像素小虎宠物

用户于 2026-10-20 确认使用补齐两侧下眼眶的像素小虎版本，并授权制作完整动画。该版本以官方小虎设定为参考，保留皇冠、额头「王」字、上挑眼神、红鼻、白脸白腹、咖色虎纹、短尾和大头小身体比例。

## 取用素材

从 `assets/manifest.json` 的 `pet-pixel-tiger-*` 别名读取。全部文件位于 `assets/pets/pixel-tiger/`：

| 文件 | 用途 |
|---|---|
| `canonical.png` | 用户确认的站姿身份参考，完整闭合的下眼眶是固定特征 |
| `spritesheet.png` | 透明 v2 精灵图，1536×2288，8列×11行，单元192×208 |
| `all-states.gif` / `all-states.mp4` | 九组动作的连续预览 |
| `look-loop.gif` | 十六个视线方向的连续预览 |
| `idle-jump-idle.gif` | 待机→跳跃→待机过渡检查 |
| `contact-sheet.png` / `direction-qa.png` | 全部帧和视线方向检查表，不作为精灵图上传 |
| `qa-stills.png` | 九状态的带时间戳静帧 |
| `metadata.json` | 帧布局、SHA256、验证摘要和已知检查提示 |

九组标准动作依次为 `idle`、`running-right`、`running-left`、`waving`、`jumping`、`failed`、`waiting`、`running`、`review`，帧数为 6/8/8/4/5/8/6/6/6。`running` 表示执行任务或思考，不能按字面改成脚步奔跑。最后两行分别容纳 000°–157.5° 与 180°–337.5°，每22.5°一帧；000°是抬头，090°是屏幕右，180°是低头，270°是屏幕左。

## 使用边界

- 复用已有版本时直接使用文件，保持 PNG 原始字节、像素比例和透明背景，不要从 GIF、检查表或缩略图重建精灵图。
- 用户要求修改时，以 `canonical.png` 和当前精灵图为身份参考，保留闭合眼眶、皇冠、王字及虎纹；新增动作或视角按非标准衍生素材记录。
- 本版本含用户已确认源图中的细微色阶，并非仅含四个精确 RGB 值的标准营销四色成品。严格四色要求仍适用于新营销排版；需要严格四色衍生版时另行制作和审核，不能宣称现文件已通过该口径。
- 技术验证通过的是当前精灵图：SHA256见metadata。四个正方向通过独立盲评，157.5°与337.5°的横向提示较轻，已结合完整视线环复核接受。更改任何像素后须重新检查相关动作与视线。
- 用户请求在 ChatGPT 创建或替换宠物时，若 Pets 工具可用，先对本地精灵图执行 `validate_pet_spritesheet`，展示对应动画，再准备上传并创建或更新。仅在用户要求时选中/启用；一次创建返回的稳定ID只属于对应账户，不写成可跨账户复用的公共ID。工具不可用时交付文件并说明限制。

本参考用于复用这套已确认素材；新动画生成和完整 QA 流程采用环境中可用的 `work-pets:create-pet` 或对应宠物维护技能，不在这里复制一套易失配的生成流水线。
